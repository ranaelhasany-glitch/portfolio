## 🚀 How to Run the Website

You can run the website in any browser using one of the following methods:

### Method 1: Direct File Opening
Double-click `index.html` or right-click `index.html` → **Open with** → your preferred browser (Chrome, Edge, Firefox, Safari).

### Method 2: VS Code Live Server
If you use VS Code:
1. Install the **Live Server** extension.
2. Right-click `index.html` and click **"Open with Live Server"**.

### Method 3: Command Line Local Server
If Node.js or Python is installed:
```bash
# Using Python:
python -m http.server 8000

# Or using npx:
npx serve .
```
Then navigate to `http://localhost:8000` or `http://localhost:3000`.

## ✏️ How to Personalize Your Contact Links & Images

1. **Email & Social Links:**
   Search for `[Your Email]`, `[Your LinkedIn]`, and `[Your Behance]` in `index.html` and replace them with your actual accounts.
2. **Project Images:**
   When you have your high-resolution project mockups or exports ready, place them in an `assets/` folder and replace the visual presentation canvases in `index.html` and `script.js`.
